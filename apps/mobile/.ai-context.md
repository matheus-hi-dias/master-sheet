# 🧠 AI Context: Master-Sheet (Mobile App)

Este arquivo serve como a "Fonte da Verdade" para o desenvolvimento assistido por IA dentro do projeto Mobile do Master-Sheet. Toda geração de views, roteamento ou consumo de dados deve respeitar as definições abaixo.

## 🎯 Visão Geral do Projeto

Este é o aplicativo mobile (para consulta rápida e edição ágil de fichas em sessões de jogo) do **Master-Sheet**. O foco principal desta aplicação é performance na rolagem, visualização clara em telas pequenas e transições suaves.

## 🏗️ Tech Stack

- **Framework:** React Native + Expo.
- **Estilização:** NativeWind (Tailwind CSS portado para React Native).
- **Roteamento:** Expo Router (para navegação baseada em arquivos/pastas).
- **Gerenciamento de Estado/Cache:** React Query (sincronização de dados offline/online e cache).
- **Iconografia:** Elementos vetoriais adaptados ou biblioteca compatível com Expo (ex: `@expo/vector-icons`).

## 🛠️ Padrões de Desenvolvimento (Guia de Estilo)

### 1. UI e Performance

- **Listas Densas:** O projeto lidará com muitas listas (Fichas, Tags, Campos de Ficha). Use sempre `FlatList` ou `FlashList` em detrimento de `ScrollView` padrão para renderizações eficientes.
- **Componentização:** Componentes base centralizados. Prefira encapsular elementos complexos do UI para facilitar manutenção.
- **Styling com NativeWind:** Use as utilidades do Tailwind repassadas via `className`. Atenção especial a transições de modo Claro/Escuro (compatibilidade nativa NativeWind).

### 2. Fluxo e Estrutura

- Priorizar a "Consulta" antes da "Edição". O layout deve ser legível como uma "ficha física" antes de o usuário interagir.
- A comunicação com o Backend NestJS envolverá envio e recebimento de tokens JWT e gestão correta de sessões.

## 📊 Regras de Negócio Mobile

1. **Renderização de Fichas (Sheets):**
   - O aplicativo precisará ler o `Template` (JSON) e compor as seções da ficha usando o conteúdo de `Sheet.data` (JSON).
   - Telas pequenas exigem que os "Setores" ou "Abas" do Template (ex: Atributos, Perícias, Equipamentos) sejam navegáveis via Swipe ou Tabs, não numa única tela gigante.
2. **Tags de Busca e Organização:**
   - A listagem de Fichas do Usuário deve poder ser filtrada pelas **Tags Privadas** (`SheetTag`) rapidamente na UI.
3. **Sincronização Lenta:**
   - Ao editar uma Ficha via celular, implementar mecanismos de "Optimistic UI Updates" com React Query para que o app não pareça travado esperando a API responder a manipulação do JSON no banco.

## 🤖 Instruções para o Agente (Antigravity)

- **Contexto Nativo:** Como se trata de React Native (Expo), não sugira dependências web puras que demandem DOM (como `react-router-dom` ou manipuladores diretos de `window`).
- **Commits:** Siga o padrão de Conventional Commits (ex: `feat(mobile): add swipe gestures to switch sheet tabs`).
- **Terminal:** Você pode rodar `npm install` e `npx expo start --clear` (se necessário resolver cache de bundle).
